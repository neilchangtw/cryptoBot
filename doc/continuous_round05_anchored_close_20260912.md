# 第5輪 T：持倉錨定量加權收盤線

前四輪已結束，沒有合格改善。此次先考慮三種機制：持倉Path R資格失效、新增鏈上歷史資訊、持倉後價量重心。Path R的200/100h慢變斜率在短持倉內預期事件較少（尚未計數）；鏈上來源歷史state回傳403，S維持DATA LIMITED。選價量重心，資料已在凍結K線且逐持倉累積。

查重：explore_vwap_position.py是20bar滾動價格位置的進場條件；theory_vwap_skew.py是單棒qv/vol位置的進場。全庫定向檢索未找到進場後才錨定、持倉中量加權收盤線失守出場。Q僅用量換MH時鐘且已拒；本輪不更動MH、不使用量鐘閾值或R續期。固定界線突破失效是9/8已拒的不同機制，本輪界線由**實際進場後的新價量**建立，不是原15bar邊界。不重新測舊滾動VWAP進場。

主假說：突破後價格若連續逆向穿過持倉後的新成交量加權收盤重心，方向延續可能衰退。此線是指標近似值，不是真實逐筆VWAP、持有人平均成本或機構買賣資料。

公式：實際entry bar=e；每個已完成持倉bar i>e，A[e,i]=sum(close[j]*volume[j],j=e+1..i)/sum(volume[j],j=e+1..i)。完全排除進場bar內未持倉路徑。L hit=close[i]<A[e,i]，S hit=close[i]>A[e,i]，相等不算；本根以前的連續2根hit且i-e>=3即触發。原SafeNet、TP、MFE、BE、MH-ext、MH平倉優先；只有原規則仍持有（含剛進extension）才新增收盤市價平倉ACX，不變動其他出場邏輯。由原始記帳處理冷卻／熔斷／替代單，不增加倉位或曝險。

資料：沿用原1h完成K/close proxy及固定funding/mark假設；最晚使用本根收盤，成交用同基準收盤代理並加0/2/5bp逆向滑價，沒有真實received-time或逐筆撮合的額外主張。任一必要bar價格非有限／非正或volume非有限／<=0即DATA LIMITED；不補值、不填0或偷跳棒。實際執行要在完整K到達後下單，只有主候選通過才檢驗额外1h延遲。

在事件和收益前鎖定：main連續2根、最早第3根；最多鄰域連續1/3根，最早第3根不變，只有main三成本全部通過才可執行。原0bp狀態、每原entry最早新增CLOSE（原仍持有）的決策差異，只算一次；24h傳遞合併，全期>=30群、2026-01-01後>=15群。沒有樣本不得計PnL。先no-op和物理前綴，再全部狀態三成本；所有淨收益+5%、loss下降、markMDD/worst30不惡化、early/late不下降和後續驗證依continuous契約。任一主門檻失敗立即拒絕，不反向、不改confirmation／minimum或加其他濾網救援。
