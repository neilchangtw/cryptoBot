## 3. 「MH 後來到 TP」的解讀

`loss_followthrough_analysis_20260904.md` 曾觀察原 MH 虧單出場後 72h 有 31/77 先到 TP，但這是**事後路徑分類**：決策當時不知道哪一筆會到 TP；等待期間仍暴露 SafeNet、funding、資金占用、其他方向交易及風控時序。該研究顯示 TP 的中位等待約 24h，遠長於本輪有限 2h grace。故本輪不以「後來到 TP」選樣，也沒有在原交易表逐筆換價；所有候選都在每根已完成棒內判斷、完整重跑交易序列。

## 4. 事先鎖定的決策與防前瞻

兩候選均只在原 SafeNet → TP → L MFE 判定未出場後生效。正浮盈原 MaxHold extension、BE、MH-ext 沿用。候選所需 `open/high/low/close` 為決策棒**已收盤**值；`ATR14` 含該棒已完成的 True Range；`close_location=(close-low)/(high-low)`；L/S 方向以符號對稱。原策略 `sma_slope` 已 `shift(1)`、突破參考為 `close.shift(1).rolling(15)`。沒有讀取下一棒或最終 MFE／MAE。研究時逐次記錄 `decision_time`、`data_cutoff_kline_open`、進場時間、當棒 OHLC 派生值、ATR、bars held；原始事件未隨版控保存。用 11,000／16,000 根截斷後，比對已完成交易與全期前綴逐欄相同。

- **A，`strength`：**在原 MH 棒，且當時價格方向性浮盈 ≤0、已完成棒的有利實體 ≥0.25 ATR、收盤位於有利端 25% 時，最多再持有 **2 根完整 1h 棒**。期間原 SafeNet／TP／MFE 優先；若轉正，沿用原正收益 extension／BE；到期仍負則 MaxHold。不是事後挑原 MH 交易。預定鄰域為實體 0.15 ATR＋有利位置 30%，以及 0.35 ATR＋有利位置 20%；時間不掃描。
- **B，`adverse`：**在原 MH **前一棒**，且方向性浮虧至少 1 ATR、棒實體逆向 ≥0.25 ATR、收盤位於不利端 25% 時，以當棒收盤市價提前一棒出場；原 SafeNet／TP／MFE 仍優先。預定鄰域僅把浮虧門檻改為 0.8／1.2 ATR。可能少虧，但也可能把下一棒會恢復的交易過早結算並改變替代交易。

候選的「延長」與「提早」均改變實際平倉時間，會改變 occupancy、同側 cooldown、替代進場、月／日熔斷與連虧冷卻；以下數字全部由同一完整序列引擎重跑，不是逐筆出場價替換。
