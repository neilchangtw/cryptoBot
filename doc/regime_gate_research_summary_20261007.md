# Regime gate 回測研究整合報告（2026-10-07）

本文件整合「10～300 小時長度比較」與「取消 gate、100～109 小時細部比較」兩輪研究。原始報告、預登記與驗證產物均保留，這次更新只整理已完成的結果。

## 結論

**這批歷史資料支持保留 Regime gate，但尚無足夠穩健證據支持把現行 100 小時改成其他長度。判定維持 NO_PROMOTION / DATA_LIMITED。**

- 取消 L/S 進場 gate：淨利由 **$6,589.79 降為 $5,992.98**，少賺 **$596.81（9.06%）**；逐時價格淨值最大回撤由 **$415.93 增為 $581.81（+39.88%）**。
- 固定門檻的第一輪粗網格以 125h 為歷史冠軍，只多賺 **$40.13**；加入 100～109h 後，107h 高於 125h，但相對 100h 只多賺 **$86.90（1.32%）**。125h 與 107h 在固定 200U 的 2／5bp 壓測均落後 100h。
- 只改進場 gate、出場分類維持 100h：第一輪粗網格冠軍為 100h；第二輪細網格冠軍為 107h，只多賺 **$41.12**，2／5bp 壓測同樣落後。
- 150h 若同時按時間換算斜率門檻，淨利為 **$7,036.39**，多 **$446.60**；這是不同設定，原始斜率門檻變成 L 6.75%／S 1.5%，並同步改變 V25-D 出場分類。僅列 **SHADOW_ONLY**，尚無全新 OOS 或前瞻驗證。

「回測最高」只代表指定資料與候選範圍中的最高值，不代表未來最佳。兩輪使用的是已反覆研究的歷史，沒有新增未見資料。

## 計算方式與比較條件

回看 H 小時是比較 **SMA200 在兩個時間點的相對變化**，不是把均線改成 SMA30／SMA50：

```text
s_H(t) = SMA200(t-1) / SMA200(t-H-1) - 1
```

例如 H=100，前一根已完成 K 棒的 SMA200 為 2,100，往前 100 小時的 SMA200 為 2,000，斜率為 `2,100 / 2,000 - 1 = 5%`。固定門檻下，L 因斜率大於 4.5% 而被阻擋；S 因絕對斜率不小於 1% 而通過此 gate，仍須符合 GK、突破、時段與風控等其餘條件。

L 的進場 gate 阻擋 `s_H > 4.5%`；S 阻擋 `|s_H| < 1%`。Regime 分類還影響 V25-D 的 TP／MaxHold，所以研究分成：

| 研究設定 | 進場 gate | V25-D 入場 regime 分類 |
|---|---|---|
| fixed_joint | 使用 s_H，固定 4.5%／1% 門檻 | 使用 s_H |
| fixed_gate_only | 使用 s_H，固定 4.5%／1% 門檻 | 維持 s_100 |
| scaled_joint | 使用 s_H×100/H，固定換算後門檻 | 使用 s_H×100/H |
| 取消 gate | 取消指定方向的進場阻擋 | 維持 s_100，保留 V25-D 出場 |

共同條件：

- ETHUSDT 1h，17,519 根；資料最後已收盤時間為 **2026-09-18 10:00（台北）**，不是研究日 10/7。
- 全部候選共同使用 `start_bar=510`，第一個可交易收盤時間為 **2024-10-09 18:00（台北）**。原生 310 起點另做重現，不能把起點差異混入長度改善。
- 下列表格採固定 **200U／20x／$4,000 名目**，`realistic=True`、既有 FEE $4＋每筆 $5 執行緩衝；0bp 表示沒有再加滑價，不是免成本。
- 另測 2／5bp 與既有 200→300→500U 保證金排程，分開比較。每組完整重播占倉、冷卻、cap、日／月熔斷、連虧與出場狀態，包含替代交易。
- 淨利為精確已平倉 PnL 加總後顯示兩位小數；MDD 為逐時含浮盈的價格淨值最大回撤，與已實現回撤、mark 回撤不同。
