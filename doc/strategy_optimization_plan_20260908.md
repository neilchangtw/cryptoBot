# 策略優化研究計畫（2026-09-08，歷史驗證已完成）

執行結果：15組單項／對照、90組成本／保證金測試、18組連續狀態WF及4組10bp壓測已完成。結論為 **NO PROMOTION**：S/DOWN TP候選證據不足，其餘候選未通過收益或風險門檻；組合試驗因MH家族未合格而跳過。詳見[執行結果](optimization_execution_20260908.md)。

以下保留執行前登記的假說、順序與淘汰標準，不因結果改動。正式策略未變更；未來獨立樣本觀察尚未執行。

## 目標

主目標：扣完整成本後提高策略期望收益，且不明顯擴大回撤與尾部損失。

次目標：降低 MaxHold 發生率、虧損金額及持倉資金占用。不能只因 MH 被改成其他出場名稱便算改善，也不要求勝率必須提高。

基準為 V14+R+V25-D，L15/S15。9/8 附件重現結果為 269 筆、PnL +7,878.15、MH 75 筆、已實現 MDD 365.44。這只是既有成交成本模型基準；加入 funding／淨值風險後需重新計算所有候選與基準。

## 第一階段：先把比較口徑補齊

1. 凍結本次 `data/maxhold_review_20260908/candles.csv`，保存來源 SHA256、程式版本及候選登記表。固定窗口不因測試結果而移動。若後續更新行情，舊窗口與新增區段分開報告。
2. 沿用現有研究引擎。新增功能關閉時，269 筆與附件逐筆一致；保留 35 筆實戰對照。
3. 主要比較固定 200U／20x，另列 200→300→500U 歷史排程。不得依排程結果挑選比較好看的版本。
4. 所有候選測額外每次市價成交 0／2／5bp；最後候選再測 10bp。費率、SafeNet 假設一致。
5. 先盤點 funding 和 mark-price 歷史是否已有可用資料，缺少則記錄資料範圍與預估用量。行情回補另按實際資料需求與環境限制處理，不在此輪執行下載。公開 funding 結算率可作回測現金流；私人收入紀錄才可核對實戰帳戶實收實付。
6. Funding 成本按實際公布的結算時點及當時持倉計算，不能拿最終公布費率提前當進場特徵；結算邊界依交易所規則固定。同步列已實現與逐時浮動淨值回撤；若缺 mark price，交易價格估算的曲線必須標明代理估計，不能宣稱已驗證強平風險。

## 第三階段：交易員常用條件的低成本診斷

以下三類先各自只套在現行 S 進場；L 原樣，TP/MH 先用基準。每類單獨測，不疊三個條件。先比對歷史研究的規則、執行假設與資料；完全重複者略過並引用既有結果。

來源只支持這些方法在交易教材／平台中有使用，不支持其能在 ETH 1h 獲利。精確數值與以下演算法是本計畫的研究定義。

### C1：成交量確認（2 組）

- 原 S 訊號成立後，要求 signal-volume / 前 20 根已完成 1h 平均 volume >= 1.0 或 1.5。
- 分母不含訊號棒；訊號棒本身已收盤，故可使用其成交量。
- 假說：有成交量參與的跌破更可能延續。反面可能性是高量已屬短期耗竭。
- 比較被拒絕交易原本的損益及完整引擎替代交易，不只算留下的勝率。
- V27 已含 vol_ratio20、taker imbalance，故優先查重，證據先驗偏低；沒有歷史改善就停止，不追加更多量能指標。
- 依據：[Schwab：Trading Volume as a Market Indicator](https://www.schwab.com/learn/story/trading-volume-as-market-indicator)。

### C2：ADX／DMI 趨勢確認（2 組）

- 使用 Wilder 平滑的 14 期 ADX／DMI，精確初始化與暖機寫入資料字典。
- 原 S 訊號成立後，要求 ADX14 >= 20 或 25，且 -DI > +DI。
- 僅用訊號棒收盤前可得 OHLC；ADX 表示強度，方向另外由 DMI 判斷。
- 假說：避開欠缺下行趨勢的跌破。風險是 GK 尋找壓縮早期，ADX 卻可能要求趨勢已形成，兩者會互相排斥、錯失早期贏家。
- 依據：[Fidelity：Directional Movement Index](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/DMI)。

### C3：跌破後回測確認進場（2 組＋2 組延遲對照）

- 原 S 訊號棒 t 收盤時，鎖定 B＝前15根1h收盤最低值，以及訊號時已知的 ATR14。
- 暫不進場，等待接下來最多 W＝1 或3根完整1h棒；不使用訊號棒自身當回測確認。
- 確認規則：該棒 high >= B−0.1×ATR14，且 close < B；代表價格接近／回到原邊界後，再收在其下。
- 出現確認後按該棒收盤後的可成交市價＋滑價進場，不能回填 B 為成交價。若先有一根 close >= B，取消事件；沒有確認則逾時取消。
- 進場當下重查時段、Path R、占倉、冷卻及熔斷；原 GK／突破只在 t 判斷，不要求回測棒再次突破。entry_regime／TP／MH 以真正進場時鎖定。
- 同方向一次最多一個 pending 事件，期間不替換成較好看的後來訊號；有持倉則不得建立 pending。信號未成交不增加月進場數。
- 兩個對照：原訊號不做確認，單純延後1或3小時進場，仍檢查相同的交易時段與風控。用於辨認改善究竟來自確認條件還是延遲。
- 同一根1h內路徑不重建；此模型只宣稱該棒曾達到邊界附近且最後收在下方，不推算棒內精確成交順序。
- 依據：[Schwab：Support and Resistance](https://www.schwab.com/learn/story/use-support-and-resistance-to-read-stock-charts)。回測確認概念與本計畫精確的1h條件並非同一件事，數值仍需驗證。

第一批最多16組：基準1＋TP3＋MH3＋交互作用1（有條件）＋量能2＋ADX2＋回測確認2＋延遲對照2。相同基準不重複計入。禁止直接跑所有條件的笛卡兒組合。

- **分批止盈／提早認輸**：V26 已研究；先稽核規則是否有明確新差異。只改名稱或小門檻不列新策略。

## 驗證順序與防止上帝視角

1. 先原引擎 parity，再單項候選，再確認候選的參數鄰域，最後才允許一次交互作用測試。所有測過的版本保留，失敗者不得刪除。
2. 歷史開發檢查以2026前與2026分開；兩者已被看過，只稱歷史分期，不能稱新OOS。
3. 計畫做六段歷史 walk-forward：2025-09起，每兩個月一段，最後一段2026-07～08。每段只能依更早資料挑該家族參數；訓練邊界前48小時不納入選擇，跨界未結束交易從訓練績效排除。若訓練交易不足100筆或受影響交易不足，該段標樣本不足。
4. Walk-forward 需真正按時間往前執行。持倉、冷卻、熔斷狀態跨段保留；既有倉位的進場參數不受下段重選影響。若現有引擎不支援狀態傳遞，先補研究介面並做無參數變更 parity，不能直接拼接各自重置狀態的回測當成可交易績效。
5. 歷史 walk-forward 仍不能消除過去看過全段資料的研究者選擇偏誤；最後候選必須用計畫鎖定後的新資料做獨立向前觀察。
6. 既有核心候選及新條件都做截斷未來資料測試，檢查指標、信號與已完成交易是否保持一致。
7. 對候選與基準按時間區塊比較增量損益，報告不確定性及多重比較調整。區塊 bootstrap 使用固定7日區塊／2,000次，保留無交易日；這是歷史差額的敏感度估計，不能代替完整市場重播或未來證明。

## 預先登記的淘汰標準

以下是本輪研究取捨，不是市場定律。

| 檢查 | 要求 |
|---|---|
| 比對與因果 | baseline parity／截斷一致性／時區檢查全部通過 |
| 扣成本改善 | 固定200U下，2026前與2026兩段增量PnL都>0；0/2/5bp皆無反轉 |
| 時序穩定性 | 六段有效WF至少4段嚴格改善；不足有效段數則不確定，不把零交易當通過 |
| 收益集中 | 移除增量最佳的一段後，總增量仍>0 |
| 風險 | 同口徑淨值MDD與最差30日損失均不惡化超過10%；另列最差單筆、SafeNet與總曝險時數 |
| 樣本 | 歷史評估段合計至少30筆實際受影響的候選事件；不足標INCONCLUSIVE |
| 鄰域 | 主候選至少一個預登記鄰近值方向一致；不可只靠孤立尖峰 |
| 勝率／MH | 必須報告，但不單獨作為優化成立的依據 |

即使全部通過，也只升為 shadow 候選。新資料觀察至少6個月且至少30筆受影響事件，再看完整成本、風險與不確定性；這個數量不是顯著性保證。未通過者保留原策略，不臨時加別的條件把結果救回來。
