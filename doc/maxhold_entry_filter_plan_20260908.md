# MaxHold 進場條件分析計畫

狀態：第一部分描述性診斷已完成，見[比較結果](maxhold_entry_diagnostic_20260908.md)。16個連續特徵及regime／時段／星期共150個非空分組，沒有找到前後期各至少10筆且均負收益的條件；未產生進入第二部分的候選，候選完整回測為0組。日期：2026-09-08。以下保留原計畫。

## 研究問題

在原策略允許進場的當下，是否存在能提前辨識負期望交易的條件，讓不開單後的完整策略扣成本收益改善？MH數量與發生率是次要結果；不能把事後已知的MH清單作為進場過濾器。

基準沿用本輪固定行情與V14+R+V25-D。固定200U、20x、額外0bp的完整funding後淨利7,926.70美元、逐時mark收盤淨值MDD368.53、269筆、MH75筆。這是策略研究帳本，不是私人帳戶淨值。來源見[本輪結果](optimization_execution_20260908.md)。

## 已知負面證據與查重

- [V27](v27_research.md)已測23個進場特徵、logistic與GBM，最佳WF AUC 0.614但置換p=0.130；單次OOS AUC約0.44～0.58，未取得可信改善證據。
- V27多單預測MH機率最高20%的靜態過濾，移除15筆、其中3筆MH，被移除交易合計獲利約306美元。此表沒有重跑完整交易序列，不等同可交易策略的最終損益。
- 本輪量能、ADX與延遲／回測確認未通過。完全相同的條件引用既有結果，不重新掃門檻；不能據此宣稱所有可能的進場資訊永久無效。
- 本輪S/DOWN TP3%未救回原75筆MH；這個出場候選與進場過濾分開研究。

## 第一部分：進場特徵與結果對照

以全部基準交易為母體，比較MH、其他虧損、淨獲利三組；另保留各出場原因。標籤僅供事後評估，不能進入特徵或決策。

| 類別 | 優先盤點欄位 | 查重與時間要求 |
|---|---|---|
| 原始訊號 | L/S、regime、GK百分位、壓縮持續時間、突破距離 | 核對V27既有公式；界線只用訊號棒之前的已完成資料 |
| 趨勢與位置 | 已知slope、距均線位置、過去報酬 | 不依出場後趨勢重新命名進場regime |
| 訊號棒 | 實體、上下影線、收盤位置、ATR、量比、主動量差 | 僅使用訊號棒已收盤值；不將持倉期MFE/MAE當進場資訊 |
| 時間與狀態 | 小時、星期、當下已平倉歷史及風控狀態 | 過去績效只能納入決策前已完成交易，查重V21/V36 |
| 新資料候選 | 5m突破形成過程 | 另訂S/L過濾假說，不改寫V37高GK做多補單的9/12規則 |

先確認覆蓋與缺值，不補假資料、不把未知值視為有利。時間需對齊訊號棒收盤與實際進場；已有shift的指標不可重複shift。

每個條件表同時列交易數、MH數／率、MH淨損益、其他虧損、贏單數／獲利、全部交易淨期望、收益集中程度及歷史分期。MH率高但總淨期望仍為正的條件，不能僅憑MH率就稱為不好的開單條件。

既有離散條件可直接分組；連續特徵不依全期最低PnL找切點。任何資料驅動分箱只在過去訓練段決定，套到後續區段；全期描述性圖表不得宣稱是樣本外證據。小樣本列筆數與不確定性，不以單筆極端虧損建立禁單規則。

## 第二部分：候選登記與完整回測

先輸出查重表及描述性診斷，再新增候選登記表：精確公式、資料可得時刻、L/S適用範圍、缺值處理、閾值來源與選擇方法。未登記前不跑自動挑最佳規則。第一批最多兩個有明確新差異的單項假說，各一個主值及一個事前鄰近值；無新證據時可停止，毋須湊滿候選。

1. 過濾只在原引擎準備進場時判斷；既有TP/MH保持基準，不與出場候選一起調整。
2. 先關閉過濾驗證原引擎一致性，再逐根完整重跑。被拒絕進場不計入實際進場數；拒單不憑空建立持倉、出場冷卻或交易損益。
3. 保留L/S占倉、日/月熔斷、月上限及連敗冷卻；後續所有訊號照新狀態判斷。若需要觀察期或禁單冷卻，必須另行明確登記，不能隱含加入。
4. 保存共同交易、消失交易、新增替代交易及結果變動。靜態移除的差額另列，不能代替引擎結果。
5. 比較固定200U及歷史保證金排程，均扣完整funding、原成本及額外0/2/5bp；最後候選補10bp壓測。
6. 特徵做截斷一致性；選參數只用先前已完成交易，沿用48h embargo與連續狀態WF。訓練基準至少100筆，受影響訓練事件至少30筆；不足維持基準並標示，不事後放寬。

報告必須拆出：避開的MH虧損、避開的其他虧損、誤殺贏家的收益、新增替代交易及其他狀態差異。只有靜態比較且無交易變動時，才能把「避免虧損減去誤殺收益」直接當作全部增量。

## 判定與限制

沿用[原計畫](strategy_optimization_plan_20260908.md)的分期、成本、回撤、最差30日、收益集中、樣本、鄰域與WF門檻，全部測試留存並做多重比較調整。另以同方向、同歷史分段、相同拒單比例的隨機過濾作研究對照，重跑完整狀態，用來檢查收益是否僅來自減少交易；隨機種子與次數須先寫入候選登記。

若MH變少但淨收益退化，不判定成功；若只有回撤下降，標為減少曝險的取捨，不改寫原收益目標。模型AUC、分類準確率或留下的勝率不能單獨決定是否採用。

這兩年資料已被反覆研究。歷史分期與WF不能消除研究者看過資料的偏誤；歷史通過最多列SHADOW，仍需鎖定後至少6個月且30筆受影響事件的新樣本，並檢查不確定性。35筆實戰附件也是已看過的資料，不稱新holdout。

本計畫只授權研究產出，不更改strategy.py、executor.py、.env、VPS或送出訂單。下一步是特徵查重與條件損益對照，尚未有可上線的禁單條件。
