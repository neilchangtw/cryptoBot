# MaxHold 延續研究第三批：因果式到期增量預測（事前登記）

前兩批各十輪未找到同時改善全策略收益與勝率且過驗證的候選。本批先查重後只找到**一個**有實質不同標籤與操作點的機制；依使用者「最多三次」上限執行這一輪，不以微調閾值、換模型名稱或相同資料重包裝湊滿十輪。V27 的目標是在進場時預測最終 MaxHold 結局；此輪在**原 MaxHold 決策時**預測若繼續持有接下來2h的方向性價格增量，兩者不同。歷史樣本仍可能很少；一條正值不會因大量先前試驗而變成確認證據。

## 唯一主候選與時間契約

決策 D 是已完成1h棒收盤，方向 `s=+1` L、`-1` S。目標標籤對每個**已過去的原基準 MaxHold 事件 j**定義為 `y_j=100×s×ln(close[j+2]/close[j])` 百分點，只用作**當下已經成熟**的訓練樣本；當前 i 僅准使用 `j+2<i`，因此標籤在 `D_i` 前已完成。這個訓練目標只預測2h方向性收盤位移，不偽裝成扣除 SafeNet/TP／funding後的真實交易增量；真正候選盈虧仍由完整狀態引擎重算。原基準 shadow 交易事件可以從當時已完成歷史價格重播取得，固定用0bp原基準作訓練集合；0／2／5bp 候選均用同一個在當時可重播的 shadow 訓練帳本。不得把 i 或之後事件放進訓練，即使預先載入完整歷史 CSV 也必須逐決策以成熟時間篩選；事件記錄訓練數、最新成熟標籤時間。

每個 j 的特徵在 j 的 MH 決策已知，固定五欄，不掃欄位：

1. 方向性當前浮損 `s×(close-entry)/ATR14`，再除2、裁在[-5,5]。
2. 方向性當根1h body `s×(close-open)/ATR14`，裁在[-5,5]。
3. 進場後至 j 的5m累積 taker 不平衡 `s×(2Σtaker_buy/Σvolume−1)`，裁在[-5,5]。
4. 已提前一小時完成的 premium 相對24h中位偏離，`s×level/0.0005`，裁在[-5,5]。
5. BTC 上一已完成1h棒的方向性 log-return，`s×log(BTCclose[j−1]/BTCclose[j−2])/0.02`，裁在[-5,5]。

任一來源缺值或路徑經過無效5m小時則該訓練／預測樣本無效。BTC 1h 補充檔以官方 checksum 驗證；premium archive 沒有當年 received_ts／不可修訂證據，正值至多 `DATA_LIMITED`／shadow。所有來源對 j/i 均有明確收盤截止；5m 不含進場前子棒，funding 不進特徵。

模型固定為含截距 ridge 線性回歸、上列**五個**非截距欄位，`λ=10`，截距不懲罰，不調模型／欄位／正則。至少30個成熟且有效的過去訓練事件才預測；否則不觸發。中心觸發 `ŷ>0` 百分點，鄰域只檢查 `ŷ>−0.10`、`ŷ>+0.10`，不挑結果。只在原 MH 到期且浮虧時給最多2根1h寬限；SafeNet、TP、MFE-trail、BE、MH-ext 按已更正封頂引擎原優先順序，L/S、occupancy、替代交易、冷卻、日月／連敗熔斷完整重算。
