# 新批次第2輪 K：扣已知模型成本後才准延長

J已先完成來源及前綴檢查，暫計88／34群但接收／修訂時點無法驗證，DATA LIMITED、候選收益0次。本輪只選K，沒有延伸J或舊A–I。

假說：原MaxHold的延長分支只要求方向價格報酬cpnl>0，卻可能尚不足支付已知的原4U完整交易成本。將「價格為正」改為「按現在可執行價估算扣模型費後為正」的延長資格，可能避免把接近損益兩平的部位繼續暴露。

公式：僅在原MH／Conditional MH時點、所有更優先原出場未觸發，原本`cpnl>0`會開始extension時，改以

`net_now = sign*qty_exact*(market_close-entry_exact) - fee_exact`；僅`net_now>0`才延長，否則原當下市價平倉。L sign=+1，S=-1；market_close為共同回測模型當前收盤加该成本情境的逆向出場滑價。qty、entry、fee均為當前已知狀態，原0bp費4U、名目4000U。

不取未来funding、最終MFE/MAE或事後原因；已付funding是沉沒現金流，仍在整體帳本按原規則保留，但不作本輪延長資格。這是成本模型下的價格報酬檢查，不聲稱私人帳戶實際佣金固定4U。SafeNet、TP、L原MFE、MH時鐘、2h extension、BE、所有入場及風控上限均不改；費用也不降低。

兩鄰域為`fee_exact*0.75`／`fee_exact*1.25`的资格門檻，僅主候選全過才跑。其餘共用契約原樣：完整狀態、跨期、0／2／5bp、30／15事件群及六項收益風險目標，失敗不救援。

直接事件：在原0bp已驗證狀態回放中，同一原持倉從非extension轉入extension的當根，當下`0<sign*(close/entry-1)<=fee/notional`。只讀當時狀態與OHLC，不讀交易終局欄位。24h連結群首歸期；群數不足則不計候選收益。

資料時點：部位與固定模型成本為自身狀態，價格為和原策略相同的已收盤OHLC；不增加外部資料接收假設。歷史1h代理成交的限制仍保留。

查重：V14/V26/V31與9/8研究改過MH長度、虧損give-up、分批與MFE保護；9/9改費用本身。本輪不改MH長度、不減費、不讀終局分類，只檢驗原正價格報酬分支是否也足付既定成本。定向搜尋fee/ext、cost/extension及「延長+費/淨」未找到該資格規則；舊整體取消extension不是本規則。
