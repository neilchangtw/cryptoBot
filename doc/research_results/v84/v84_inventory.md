## 3. 是否還有一個合格的新機制

判斷標準（依使用者指示，按機制與時間戳選，不按績效）：(1) 機制與上表及 H001 都不同；(2) 決策時可觀察，時間戳明確；(3) 現有 9 個網域就拿得到（不再擴大）；(4) 一次便宜診斷就能否證。

逐一檢查還沒用過的免費欄位：

| 想法 | 不合格原因 |
|---|---|
| Deribit 未平倉／交易商 gamma | 歷史 API 只有成交，沒有逐日各履約價未平倉，資料不足 |
| Deribit 期限結構、賣權占比、偏斜 | V60～V63、V72-A、V73 已測 |
| CFTC 其他分類（資產管理者、交易商） | 與 V83-C 同一份報告、同一發布時點；屬 C 的變體，使用者已禁止 |
| CME 日線基差、未平倉 | Yahoo 只有近月拼接價，沒有未平倉；基差與 V54 同機制 |
| 穩定幣發行、交易所淨流入 | V59 已測，且資料是重算版，不是當時可見值 |
| Coinbase 溢價 | 與 V55 同機制 |
| ETH／BTC、跨幣 | V9、V12-R4、V42-B、V44-R11、V52 已測 |
| Dukascopy 指數或黃金日內連動 | 22.5bp 成本下限排除分鐘連動；殘差回歸與 V9 同機制；資料約三成請求失敗 |
| 資金費結算前後漂移、溢價指數、5 分 K | V58 篩選為已失敗機制重疊 |

**結論：在現有資料與網域內，找不到同時滿足四個條件的新機制。本輪不做新回測，第四階段（帳戶回測）未執行。** 總結用語：在已測範圍內尚未找到通過全部門檻的候選。
