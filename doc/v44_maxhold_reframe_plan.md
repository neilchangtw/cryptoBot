# V44 預登記：跳出「單筆出場時機」框架解決 MaxHold（2026-10-31）

## 1. 反省：過去 ~80 輪 MaxHold 研究共用的框架

V25／V26／V31／V33、9/8、9/23～9/24 的研究幾乎都假設：

1. **部位大小在進場就固定 100%**，只研究「什麼時候出場」。
2. **決策點在 MH 到期那根或進場那根**，問題被寫成「這筆會不會變贏家」的分類題。
3. **MH 出場後就結束**，失敗突破本身不被當成資訊或機會。

V26 已證明在 MH 決策時贏家輸家還分不開，所以框架 2 下的規則注定砍到贏家。
本輪改變的是 1 和 3，不再嘗試預測單筆結局。

## 2. 來源（知名交易員的公開方法）

- **試單後確認加碼**：Jesse Livermore「先試單、對了再加」；Turtle 規則在有利 ½N 時加碼。
  核心是讓「輸家天生只有小部位、贏家才有完整部位」，不需要預測。
- **失敗突破反手**：Linda Raschke《Street Smarts》Turtle Soup、Al Brooks 的 trapped traders：
  突破失敗後被套的人停損，價格往反方向走。

## 3. 去重

- V23 Path V／V30：依「進場特徵」調整部位 → 已否決。R1 依「持倉中價格路徑」加碼，不同。
- dual_strategy 金字塔：多訊號同時觸發疊單，不同。
- V26 R2/R3 分批止盈／止損：是減碼；R1 是加碼，鏡像相反。
- 早期 r01～r05「止損反手」是舊 BTC 系統，未在 V14 MH 上測；9/8 突破失敗研究只做描述與提早出場，沒有反手交易。

## 4. 規則（鎖定，看結果前不改）

共同：引擎 = `v14_export_trades.py` 的 V14+R+V25-D 完整狀態（L/S、cooldown、熔斷、連虧冷卻），
`realistic=True`、每筆 extra_cost $5、固定 200U（名目 $4,000），手續費依名目比例。
進出場時點、出場原因與基準完全相同，差別只在部位與附加交易。

### R1 試單加碼（Probe & Add）
- 進場只開 50% 名目（$2,000）。
- 持倉中任一根收盤的方向性浮盈 ≥ k × ATR14%（進場 bar 計算，ATR/close），且尚未進入延長期，
  於該根收盤加碼另外 50%（逆向滑價同基準），每筆最多加一次。
- 出場（SN/TP/MFE/MH/BE/MHx）完全照原規則、以原進場價判斷；兩段各自計算損益。
- 中心 k = 0.5（Turtle ½N），鄰域 k = 0.25、0.75。
- 最大名目不超過基準，不增加曝險。

### R2 失敗突破反手（Failure Reverse）
- 原策略以 **MH** 出場（虧損到期）時，同根收盤開反向單（獨立倉位，200U），與主策略互不占用。
- 反手單：TP 2.0%、SafeNet 2.0%（含 25% 穿透）、最長 H 根收盤出場，不延長。
- 中心 H = 6，鄰域 H = 4、8。
- 反手單不計入主策略熔斷（獨立帳）。

## 6. 第 3 輪（2026-10-31 追加，依 5.5 年診斷）：波動時鐘 MaxHold

診斷（`v44_mh_diagnosis.py`，VPS 5.5 年）：進場 ATR14% 越低 MH 比例越高（L 低／高三分位 39%／15%，S 35%／24%），
2026-06～10 進場 ATR 中位 0.69～0.77%（歷史約 1.0%）；實戰出場原因與回測 50/50 一致。
固定 % 的 TP 在低波動下需要更多時間，MH 根數卻固定。

去重：低波動不進場（V24 Direction A、10/29 S ATR<1%）與依 ATR 縮 TP（9/04、10/29）已否決；
依 regime 改 MH（V25）不是依波動。**依進場波動調整 MH 根數**未曾測過。

規則（鎖定）：mult = clip(ATR_ref / ATR_entry, 下限, 上限)，ATR_ref = 過去一年（8,760 根，至少 90 天）ATR14% 中位數，不含當根。
MH 根數 = round(原 MH × mult)（含 L regime MH 與 bar2 縮減後的 5 根；S 含 UP 8 根）。其他規則全不變。
- A（只拉長）中心 [1, 1.5]，鄰域 [1, 1.25]、[1, 2.0]
- B（對稱）中心 [1/1.5, 1.5]，鄰域 [0.8, 1.25]、[0.5, 2.0]

資料：VPS `data/v39/ETH_1h_long.csv`，開發 = 進場 < 2024-11-01，保留 = 之後。固定 200U、realistic、每筆 +$5。
門檻：G1 開發 PnL ≥ 基準 +5% 且 MH 桶少虧；G2 保留 PnL ≥ 基準；G3 兩個鄰域開發 > 基準且保留 ≥ 基準；
G4 2bp、5bp 全期 > 基準；G5 MDD ≤ 基準 ×1.2；G6 全期 WR 不降超過 1pp。全過才列 SHADOW 候選，不直接改實盤。

**揭露**：腳本在本機 2 年資料（2024-10～2026-10，≈ 保留期）做過程式測試，已看到保留期結果：
A1.5 0bp +$38（2025 -$420、2026 +$458）、2bp/5bp 低於基準；B1.5 低於基準。因此保留期已非盲測，
本輪的真正新資訊只剩開發期 2021～2024。
